# Supabase shared data implementation plan

> Execution : sous-tâches indépendantes Sol 6.1, intégration et vérifications par l'agent principal.

**Goal:** Partager données persistantes, documents et réglages entre local et Vercel, avec authentification.
**Architecture:** Domaine existant + PostgreSQL versionné, Auth et Storage privés.
**Spec:** ../specs/2026-11-06-supabase-design.md

## Contraintes et vérifications

Pas de secrets Git ; pas d'appel Chronopost réel ; import non destructif ; configuration manquante bloque ; les validations locales ne sont pas des validations du cloud.

- [x] Socle `src/lib/supabase/{config,admin,storage,settings}.ts`, migration SQL état/membres/réglages, dépôt partagé et CAS. Tests concurrence/conflit/reset/configuration/chiffrement.
- [x] Auth serveur, garde async pour toutes les routes, connexion/déconnexion et état partagé visible. Tests session absente, membre absent, origine refusée, secret non divulgué.
- [x] Persistance Chronopost avec claim SQL et finalisation conditionnelle, stockage privé, tests anti-doublon et erreurs. Pas de relance après crash.
- [x] Médias et réglages communs ; script d'import idempotent des données locales et documents, verrou orphelin conservé. Vérifier absence de fuite de clés, d'écrasement et de reset.
- [x] Projet Supabase existant : migrations appliquées par Sofiane, membres créés, données et documents importés, local activé et connexion réelle vérifiée.
- [ ] Vercel : variables à saisir par Sofiane et redéploiement, puis vérification des deux environnements.
- [ ] Tests unitaires, types, build, navigateur, revue puis publication GitHub. Documenter tout blocage distant.

## Interfaces partagées

`isSupabaseMode(): boolean`, `getSupabaseAdmin(): SupabaseClient` dans config.ts/admin.ts. Variables : NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY, SUPABASE_SECRET_KEY, CRM_SETTINGS_ENCRYPTION_KEY (32 octets base64).
`uploadPrivateObject(path: string, bytes: Uint8Array, contentType: string): Promise<void>` (sans écrasement) et `downloadPrivateObject(path: string): Promise<Buffer>` dans storage.ts, bucket crm-private.
Root : état/réglages/médias/import/migration core. Agent Auth : garde, routes, connexion, UI CRM. Agent Chronopost : chronopost.ts, stores, migration claim et tests.
